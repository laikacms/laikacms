  Laika is a content API. Define your content once and serve it as a JSON:API to your editors, sites
  and apps. It runs on your own infrastructure, on top of the filesystem, a database, a Git
  repository or a content service you already use. More than 40 backends are supported.

<Features heading="Open source, on your own infrastructure.">
  Laika puts an API in front of your content. The storage behind it is a configuration choice, so
  you can switch backends without rewriting your application. Everything is MIT licensed and
  self-hosted.

  <PillarGrid>
    <Pillar icon="scales" title="MIT licensed" badge="MIT">
      The license won't change in newer releases. Self-hosting is the default, and the source is on
      GitHub.
    </Pillar>

    <Pillar icon="layers" title="Headless">
      Your content lives behind an API, separate from any theme. Render it with React, Vue, Astro, a
      static site generator or a mobile app, all from the same source.
    </Pillar>

    <Pillar icon="swap" title="40+ backends">
      Store your content on the filesystem, object storage, a Git repository, any SQL database,
      MongoDB, Notion, Neo4j or IPFS. Switching backends is a one-line change.
    </Pillar>

    <Pillar icon="spark" title="One API for everything">
      Your editors, your site build and your apps use the same endpoints. There is no separate
      delivery API to keep in sync.
    </Pillar>

    <Pillar icon="globe" title="Any JavaScript runtime">
      The API returns a standard fetch handler, so the same code runs on Node, Bun, Deno, Cloudflare
      Workers and in the browser.
    </Pillar>

    <Pillar icon="cube" title="API-first">
      A JSON:API over your content. Connect Decap CMS to it, or build your own front end on the same
      endpoints.
    </Pillar>

    <Pillar icon="book" title="Pluggable serializers">
      Store content as JSON, YAML, Markdown with frontmatter or raw bytes. You choose the format on
      disk.
    </Pillar>

    <Pillar icon="decap" title="Works with Decap">
      A git-gateway-compatible HTTP handler with OAuth2 and PKCE built in. Connect Decap CMS to Laika
      directly, or run the gateway yourself. All MIT.
    </Pillar>

    <Pillar icon="plug" title="Developed in the open">
      Developed on GitHub with changesets and public issues. Contributions and new adapters are
      welcome.
    </Pillar>
  </PillarGrid>
</Features>
