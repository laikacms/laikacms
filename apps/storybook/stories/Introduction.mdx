# Laika CMS — UI Storybook

This Storybook covers the React UI that ships in the Laika CMS workspace. Stories import each
package through its real public specifiers; the Storybook Vite config aliases those specifiers to
the packages' TypeScript source, so what you see here renders straight from `src`.

Use the **Theme** toolbar control (top of the canvas) to flip every story between the editor's
light and dark design tokens.

## Packages with stories

### `decap-cms-widget-lexicaleditor`

The Lexical rich-text widget, built as an emotion-styled fork of shadcn-editor. Its
`editor/ui/*` directory is a self-contained component library (button, input, select, dialog,
popover, command palette, calendar, …) — the bulk of the stories here, grouped under
**Lexical Editor / UI**.

### `@laikacms/decap-integrations` (`packages/decap`)

Custom Decap CMS widgets. The icon pickers — Lucide and Radix — are rendered under
**Decap Integrations** with mocked widget control/preview props.

### `decap-cms-widget-portabletext-editor`

A Decap widget backed by `@portabletext/editor`. The `PortableTextEditorView` is self-contained
(it owns its `EditorProvider`), so it renders as a live editor with its toolbar under
**Portable Text Editor**.

### `@laikacms/decap-ai`

Its `AiChatControl` is a `react-redux`-connected widget driven by a streaming chat backend
(`useChat`). The **Decap AI** story mounts it with a minimal mock redux store and a stubbed `fetch`,
so the chat shell renders standalone — actually sending a message still needs a live AI endpoint.
(`AiChatPreview` renders `null`, so it has no story.)

## Packages without isolated stories

- **`decap-cms-lexical-core`** — exposes a Lexical `DecoratorNode` subclass and a React context
  provider for custom blocks. The block UI itself lives in the Lexical widget package; core has no
  standalone presentational component to show.
