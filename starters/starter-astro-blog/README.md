# starter-astro-blog

Minimal static blog built with [Astro](https://astro.build) and LaikaCMS:

- **`@laikacms/astro`** — content reaches your pages through `astro:content`, so you use
  `getCollection`, `getEntry` and `render` exactly as you would with local markdown files.
- **Local JSON API** — the integration mounts `/__laika` only while `astro dev` is running.
- **Bare Decap admin, no CDN** — the non-laika bare app (`@laikacms/decap-cms/laika-app/bare`) is
  bundled by Vite; `src/cms.ts` registers exactly the backends, widgets, and locales this site uses.

## Quick start

Always start from the wizard — it copies this starter and generates `src/cms.ts` from your
backend/widget/locale choices:

```bash
npx laikacli create
```

Or, working inside this checkout directly — the `starters/pnpm-workspace.yaml` carries `link:`
overrides for packages ahead of npm, so those packages must be built first:

```bash
# Build the linked packages (run from this directory)
pnpm -C ../.. --filter laikacms --filter @laikacms/server --filter @laikacms/vite-plugin build

pnpm install
pnpm dev
```

Open <http://localhost:4321> for the blog and <http://localhost:4321/admin/> for the CMS editor (dev
auth — no login required). Posts you create in the admin appear on the site without restarting the
dev server.

## Project layout

```
src/
  cms.ts                 # CMS registrations (backends/widgets/locales) — generated by `laika create`
  decap-config.ts        # Shared collection schema
  content.config.ts      # Astro content collections, backed by the Laika loader
  pages/
    index.astro          # Blog homepage — lists published posts
    blog/[...id].astro   # Individual post
    admin/index.astro    # Decap CMS admin UI (bare app + src/cms.ts)
content/                 # Filesystem content root (git-tracked)
```

## How content reading works

`src/content.config.ts` declares the collection:

```ts
import { documentsLoader } from '@laikacms/astro/loader';
import { defineCollection, z } from 'astro:content';

const posts = defineCollection({
  loader: documentsLoader({ dir: 'content', defaultExtension: 'md' }),
  schema: z.object({ title: z.string(), date: z.coerce.date() }),
});
```

The Astro collection name is the Laika collection, so `posts` reads documents under the `posts/` key
prefix — the folder Decap writes to. Pages then read it the ordinary Astro way:

```ts
const posts = await getCollection('posts');
```

The route is `blog/[...id].astro` rather than `[slug]` because a document key can be nested
(`posts/2026/hello` → id `2026/hello`), and a rest parameter is what lets the slash survive.

## Rendering markdown

The `body` field from Decap CMS is markdown, and Astro renders it through its own pipeline:

```astro
const { Content } = await render(post);
<Content />
```

To add remark/rehype plugins or MDX, configure them in `astro.config.mjs` as you would for any Astro
project.

## Deployment

Build a static site:

```bash
pnpm build
```

Deploy the generated `dist/` directory to any static host. The local JSON API is not included — the
integration only mounts it on the dev server.
