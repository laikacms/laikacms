# starter-astro-blog

Minimal static blog built with [Astro](https://astro.build) and LaikaCMS:

- **`@laikacms/vite-plugin`** — imports filesystem content at build time and hot reloads it in dev.
- **Local JSON API** — `localApi: true` mounts `/__laika` only while `astro dev` is running.
- **Bare Decap admin, no CDN** — the non-laika bare app (`@laikacms/decap-cms/app/bare`) is bundled by
  Vite; `src/cms.ts` registers exactly the backends, widgets, and locales this site uses.

## Quick start

Always start from the wizard — it copies this starter and generates `src/cms.ts` from your
backend/widget/locale choices:

```bash
npx laikacli create
```

Or, working inside this checkout directly:

```bash
pnpm install
pnpm dev
```

Open <http://localhost:4321> for the blog and <http://localhost:4321/admin/> for the CMS editor (dev
auth — no login required).

## Project layout

```
src/
  cms.ts                 # CMS registrations (backends/widgets/locales) — generated by `laika create`
  decap-config.ts        # Shared collection schema
  pages/
    index.astro          # Blog homepage — lists published posts
    blog/[slug].astro    # Individual post
    admin/index.astro    # Decap CMS admin UI (bare app + src/cms.ts)
content/                 # Filesystem content root (git-tracked)
```

## How content reading works

```ts
const posts = import.meta.glob('laika:doc/posts/*', { eager: true });
```

## Rendering markdown

The `body` field from Decap CMS is raw markdown. This starter renders it inside a `<pre>` so the
content is visible without additional dependencies. In production you'd pipe it through
remark/rehype or use Astro's built-in `<Content>` component with a `.md` source.

## Deployment

Build a static site:

```bash
pnpm build
```

Deploy the generated `dist/` directory to any static host. The local JSON API is not included.
