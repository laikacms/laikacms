# Cloudflare R2

`R2StorageRepository` stores content in a Cloudflare R2 bucket — the natural choice on Cloudflare
Workers, where the bucket arrives as a binding. There is also `assets-r2`, an
[Assets-protocol](../concepts/assets) implementation for binary media on R2.

## Wire it up

```ts
import { R2StorageRepository } from 'laikacms/storage-r2';
import { markdownSerializer } from 'laikacms/storage-serializers-markdown';

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const storage = new R2StorageRepository(env.CONTENT_BUCKET, { md: markdownSerializer }, 'md');
    // …
  },
};
```

```toml
# wrangler.toml
[[r2_buckets]]
binding = "CONTENT_BUCKET"
bucket_name = "content"
```

For binary assets:

```ts
import { R2AssetsRepository } from 'laikacms/assets-r2';
```

## Capability notes

- Edge-compatible — no Node.js APIs required.
- Constructor takes an `R2Bucket`; the [S3 adapter](./s3) (`createS3Bucket()`) produces one from any
  S3-compatible service, so this repository also fronts MinIO, Backblaze B2, and friends.
- For a starter running Workers + D1 + R2, see
  [`starter-workers-blog`](../getting-started/starters).
