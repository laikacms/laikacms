# S3 (and compatibles)

Two official routes to S3-shaped storage:

- **`@laikacms/aws/storage-s3`** — a full S3-backed `StorageRepository` (also works with MinIO,
  Backblaze B2, DigitalOcean Spaces). Use this on AWS.
- **`laikacms/storage-s3`** — a small adapter, `createS3Bucket()`, that makes any S3-compatible
  client look like an `R2Bucket` so the existing [`R2StorageRepository`](./r2) can be reused
  unchanged. Use this when you're already in the `laikacms`-only dependency footprint.

Neither pulls the AWS SDK into your bundle uninvited — the SDK client and command constructors are
passed in by the caller.

## The adapter route

```ts
import {
  DeleteObjectCommand,
  GetObjectCommand,
  HeadObjectCommand,
  ListObjectsV2Command,
  PutObjectCommand,
  S3Client,
} from '@aws-sdk/client-s3';
import { R2StorageRepository } from 'laikacms/storage-r2';
import { createS3Bucket } from 'laikacms/storage-s3';
import { jsonSerializer } from 'laikacms/storage-serializers-json';

const s3 = new S3Client({
  region: 'auto',
  endpoint: process.env.S3_ENDPOINT, // MinIO, B2, Spaces, or omit for AWS
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY!,
    secretAccessKey: process.env.S3_SECRET_KEY!,
  },
});

const bucket = createS3Bucket({
  client: s3,
  bucket: 'content',
  commands: {
    GetObjectCommand,
    PutObjectCommand,
    DeleteObjectCommand,
    HeadObjectCommand,
    ListObjectsV2Command,
  },
});
const storage = new R2StorageRepository(bucket, { json: jsonSerializer }, 'json');
```

## The AWS package route

```bash
pnpm add @laikacms/aws
```

`@laikacms/aws/storage-s3` is the full S3 `StorageRepository`; the package also ships
`@laikacms/aws/assets-s3` (S3-backed assets) and DynamoDB implementations — see
[DynamoDB](./dynamodb).

## Capability notes

- Object storage has no real folders — folder semantics come from key prefixes, which the storage
  protocol's slash convention maps onto directly.
- S3 ETags serve as opaque versions where the protocol exposes them.
